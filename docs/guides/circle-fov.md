# Circle FOV

Use Filter Circle to limit target selection and Render Overlay to display the circle. Lower the radius percentage to shrink the active area.

First-launch config:

```ini
circle_fov_enabled = true
circle_fov_radius_percent = 100
circle_fov_show_preview = true
game_overlay_draw_circle_fov = true
```

For an existing workspace, edit the node inputs. See [overlay settings](overlay.md).
